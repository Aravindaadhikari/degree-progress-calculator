# Degree Progress & Target Calculators

This repository contains browser-based GPA/CGPA planning tools for:

- Full-Time students
- Part-Time and Apprenticeship students

## Files

- `index.html` — landing page
- `full-time.html` — Full-Time calculator
- `pt-apprenticeship.html` — Part-Time & Apprenticeship calculator

The calculators run entirely in the user's browser. No student marks are transmitted to a server.

## GitHub Pages

In GitHub:
1. Open **Settings**
2. Select **Pages**
3. Under **Build and deployment**, choose **Deploy from a branch**
4. Select `main` and `/root`
5. Save

Your landing page will then be available at your GitHub Pages URL.
